# Модуль интеграции форм с Bitrix24 (b24contactdeal)

Модуль для двусторонней синхронизации формы "Задать вопрос" на сайте (Bitrix) со сделками в облачном Bitrix24.

## Функциональность

*   **Отправка данных:** Все данные, отправленные через форму "Задать вопрос" (Событие "FEEDBACK_FORM"), автоматически создают новую сделку в указанном Bitrix24.
*   **Источник сделки:** В создаваемой сделке автоматически проставляется источник "Веб-сайт".
*   **Контакт:** При создании сделки происходит получение пользователя по указанному email. Если email существует в облачном б24, то у сделки будет указан уже существующий контакт, в противном случае создастся новый контакт.
*   **Статус сделки:** Модуль предоставляет механизм для обновления статуса заявки на сайте в соответствии со статусом сделки в Bitrix24.
*   **Миграции БД:** Все изменения в структуре базы данных сайта реализованы через миграции с помощью модуля sprint.migration.

## Установка и настройка

### 1. Настройка Bitrix24

#### А. Входящий вебхук (для отправки данных с сайта в B24)
1.  Создайте **входящий вебхук**.
2.  Выдайте права: `CRM`.
3.  Скопируйте сгенерированный URL. Он понадобится далее.

#### Б. Исходящий вебхук (для получения обновлений из B24 на сайт)
1.  В том же разделе создайте **исходящий вебхук**.
2.  Выберите события: `ONCRMDEALADD`, `ONCRMDEALUPDATE`.
3.  В поле "URL обработчика" укажите: `https://ваш-сайт.ru/local/modules/b24contactdeal/B24WebhookHandler.php`
4.  Скопируйте **Токен приложения**. Он понадобится далее.

### Установка модуля на сайт

1. Установите модуль sprint.migration через маркетплейс https://marketplace.1c-bitrix.ru/solutions/sprint.migration/
2. Перенесите модуль b24contactdeal в директорию /bitrix-site/local/modules/
3. В административной панели битрикс перейдите в Настройки -> Модули -> "Интеграция формы "Задать вопрос" с Bitrix24 (b24contactdeal)" -> Установить

### Конфигурация

В файле /bitrix-site/local/modules/b24contactdeal/include.php установите свои переменные:
* Вместо **#YOUR_API_URL_FOR_CREAD_DEAL#** вставьте вашу ссылку входящего вебхука.
* Вместо **#YOUR_UF_CRM_FIELD_ID#** вставьте id вашего поля из облачного б24 для комментария.
* Вместо **#YOUR_WEBHOOK_APPLICATION_TOKEN#** вставьте ваш application token исходящего вебхука.

## Использование

После установки:

1. При отправке формы "Задать вопрос" в указанном Bitrix24 будет создана новая сделка.
2. Информация о заявке сохраняется в Highload-блок ContactDeal.
* UF_B24_DEAL_ID - ID сделки в Bitrix24.
* UF_B24_DEAL_STATUS - её текущий статус.
3. При изменении статуса этой сделки в Bitrix24 значение UF_B24_DEAL_STATUS на сайте будет автоматически обновлено.
